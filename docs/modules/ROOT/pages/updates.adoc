= What's New

[.lead]
_The book is updated as the field moves. This page records what changed and when._

[.in-short]
*In short:* _The Blueprint_ is a living field guide. Its method for organising people and AI agents is meant to outlast any particular model, but the evidence, tools and examples change every few months, so the book is revised at least once a quarter and every change is dated here.
